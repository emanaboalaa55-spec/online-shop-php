# 🛒 E-Commerce Web Application (Native PHP & MySQL)

مشروع متجر إلكتروني متكامل لإدارة المنتجات والمبيعات تم تطويره باستخدام PHP بدون أطر عمل (Native PHP) مع قاعدة بيانات MySQL وتصميم تجاوبي باستخدام HTML, CSS, JavaScript, و Bootstrap.

---

## 🌟 المميزات (Features)

* **واجهة المستخدم (Frontend):**
  * عرض المنتجات وتصفح الأقسام بشكل مرن وتفاعلي.
  * سلة تسوق (Shopping Cart) لإضافة وتعديل المنتجات.
  * تصميم تجاوبي يعمل بسلاسة على الشاشات المختلفة.

* **لوحة التحكم (Admin Dashboard):**
  * إدارة كاملة للمنتجات (إضافة، تعديل، حذف، رفع صور المنتجات).
  * إدارة الأقسام والتصنيفات (Categories).
  * صلاحيات المستخدمين وإدارة الحسابات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** Native PHP
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap, jQuery
* **Tools & Environment:** XAMPP, VS Code, Git & GitHub
